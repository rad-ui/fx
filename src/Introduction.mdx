# rad-ui-fx

**A UI effects library for modern web applications**

rad-ui-fx is a TypeScript library that provides a collection of animation and visual effects to enhance your web applications. It's built on top of popular motion libraries like `framer-motion` and `motion`, providing a consistent API across them.

## Features

- 🌟 **Easy to use animation utilities**
- 🎭 **Pre-built animation components**
- 🔄 **Compatible with both framer-motion and motion libraries**
- 📦 **TypeScript support with full type definitions**
- 📝 **Well-documented API with examples**

## Quick Start

### Installation

```bash
npm install rad-ui-fx
```

### Basic Usage

#### Animation Utilities

```tsx
import { motion } from 'framer-motion'; // or from 'motion'
import { createFadeAnimation } from 'rad-ui-fx';

const fadeVariants = createFadeAnimation({ duration: 0.8 });

function MyComponent() {
  return (
    <motion.div
      initial="hidden"
      animate="visible"
      variants={fadeVariants}
    >
      Fade me in!
    </motion.div>
  );
}
```

#### Pre-built Components

```tsx
import { FadeInBox, SlideInBox } from 'rad-ui-fx';

function MyApp() {
  return (
    <div>
      <FadeInBox duration={0.8} delay={0.2}>
        This content fades in
      </FadeInBox>
      
      <SlideInBox direction="left" distance={100} duration={0.6}>
        This content slides in from the left
      </SlideInBox>
    </div>
  );
}
```
